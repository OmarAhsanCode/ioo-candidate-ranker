# Accurate Candidate Ranking System — Team IOO

An AI-powered candidate ranking system built for the India Runs at Active Skills — Data & AI Challenge 2026.

## What it does
Upload a candidates JSONL file and paste a job description. The system scores and ranks candidates using a two-stage pipeline — feature extraction followed by weighted scoring across skills, career trajectory, experience, location, and behavioral signals.

## How to run locally
pip install -r requirements.txt
streamlit run app.py
